# GoogleFonts_extra

Dodane 2026-09-10 po audycie fontow pod ksztalty "k"/"a" (bledy k->h, a->o w OCR).
Zrodlo: https://github.com/google/fonts (katalog ofl/), licencja SIL Open Font License 1.1.
Wybrane: recznie pisane, z pelnym zestawem polskich znakow; rodzina Playwrite to
szkolne pismo elementarzowe (k z petla). Fonty zmienne ([wght]) renderuja sie
w domyslnej instancji.
